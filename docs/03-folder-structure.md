# 3. Folder Structure

## 3.1 Conventions

- **`app/`** — routes only (pages, layouts, route handlers). No business logic lives here beyond composing components and calling `services/`.
- **`components/`** — presentational + light-interactive UI, grouped by domain (`exam/`, `resource/`, `dashboard/`...) plus `ui/` for Shadcn primitives and `shared/` for cross-domain pieces (the `IndexChip`, `EmptyState`, etc).
- **`lib/`** — framework glue: Prisma client singleton, Firebase client/admin SDKs, Zod schemas, rate limiter, generic utils. Things that configure infrastructure.
- **`services/`** — the data-access layer. Every Prisma query lives here, never directly in an API route or a page. This is what makes the same "get recommended exams" logic reusable from a Server Component, an API route, and (later) a cron job.
- **`hooks/`** — client-side React hooks (`useAuth`, `useDebounce`, `useOnboarding`).
- **`types/`** — shared TypeScript types not generated by Prisma (e.g. API response shapes, filter param shapes).
- **`prisma/`** — schema + migrations + seed script.
